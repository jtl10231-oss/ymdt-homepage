## 5. 브랜드 마크

### YMDT (회사) — 2026-09-29 신규
- **인장 모노그램**: 접힌 모서리 타일(우하단만 꺾임)에 굵은 로만 세리프 YM/DT 네 글자를 도장처럼 2×2로 새겼다. 이름 옆에 도장을 찍는 한국식 서명에서 착안.
- **워드마크**: 직접 그린 굵은 로만 세리프(기둥 9 / 가는 획 3.2, 캡 높이 46). HANI 워드마크가 A 가로획 하나만 색을 쓰듯, **Y의 가는 획 하나만 강조색**(종이 위 플럼 액센트, 어두운 판 위 샴페인 금).
- **락업**: [인장 모노그램] + [워드마크]. 어두운 배경에서는 종이색 타일로 반전.
- 버린 안: 둥근 두 갈래 Y(새총처럼 읽힘), 보라 타일 + Y 한 글자(야후 로고 연상).

### HANI 제품 마크
HANI 워드마크는 원본 좌표에 같은 색 외곽선을 더해 **더 굵게** 쓴다(기본 weight 1.6, MatchOS 락업 2).

| 마크 | 형태 | 홈페이지 용도 |
|---|---|---|
| **결(結) 엠블럼** | 맞물린 두 반지(실제 위빙) — **HANI MatchOS 전용** | MatchOS 락업, MatchOS 페이지 |
| **HANI 워드마크** | 직접 그린 로만 세리프, A 가로획만 플럼 (굵게) | HANI MatchOS 락업, 푸터 |
| **팔각 인장** | 팔각 이중 테두리 + 반지 각인, -3° | HANI 인장 스탬프 모션 (파비콘은 YMDT 모노그램) |
| **원앙 엠블럼** | 브로셔의 금색 원앙 한 쌍 | MatchOS 다크 섹션·파트너십 |
| **사주앱 앱 아이콘** | 플럼 사각 + 흰 H + 반짝임 | 사주앱 페이지 |
| **하니 캐릭터** | 라벤더빛 말랑한 3D 캐릭터가 보라 하트를 안고 눈을 감고 미소 | 사주앱 페이지 전면 활용 |

## 6. 시그니처 요소 (홈페이지 전용 조합)

1. **금실(Thread)**: 스크롤에 따라 그려지는 한 가닥의 선. 섹션과 섹션을 꿰매듯 잇는다.
2. **인장 스탬프**: 핵심 문장 옆에 0.5초 오버슈트로 찍힌다. 반복·회전 없음.
3. **성좌 네트워크**: 우리 업체(중심)와 파트너 업체(주변)가 금선으로 이어진다.
4. **에디토리얼 헤더**: 영문 아이브로우 + 헤어라인 + 페이지 번호 표기(브로셔 문법).
5. **실물 화면 무대**: 직접 만든 브라우저·휴대폰 프레임 안에 실제 앱 화면.

## 7. 모션

- 기본은 조용하게: 투명도, 약간의 위치(12~24px), 깊이, 선 그리기.
- 허용 예외: 금실 그리기, 인장 스탬프, 숫자 카운트업, 성좌의 느린 호흡.
- 금지: 바운스, 회전, 무한 반짝임, 과한 패럴랙스.
- `prefers-reduced-motion`이면 장식 모션을 끄고 최종 상태를 바로 보여준다.
- 이징 기본값 `cubic-bezier(0.22, 1, 0.36, 1)`, 길이 0.6~0.9s.

## 8. 목소리(카피)

**대표 문장 (확정)**: 한 사람을 깊이, 두 사람을 가깝게
- 한 사람을 깊이 = HANI 앱(나를 이해) · 두 사람을 가깝게 = HANI MatchOS(좋은 만남). 먼저 한 사람을 깊이 알고 그다음 두 사람을 잇는, 좋은 중매의 순서이기도 하다.
- 회사 정의: "YMDT는 사람을 이해하는 기술을 만듭니다."
- 모든 사용처(히어로·푸터·탭 제목·공유 정보)는 `lib/site.ts`의 `BRAND`를 쓴다.
- 쓰지 않는 표현: 인연을 횟수로 세는 말("더 자주 닿도록"), 무엇을 만드는지 안 보이는 추상어("구조를 만듭니다"), "~도록"으로 끝나 문장이 닫히지 않는 헤드라인.


- 브로셔처럼 짧은 두 줄 대구: "운영은 하나로 / 매칭풀은 더 크게".
- 판단의 주인공은 사람: "사주는 선택, 판단의 중심은 매니저와 회원".
- **사주앱**은 "사주로 나를 읽고, 대화로 나를 이해하는" 자기이해 앱. 운세·점술·예측 표현을 쓰지 않는다.
- 검증되지 않은 수치·고객사 이름은 쓰지 않는다. 200 → 4,000명은 "연결된다면" 시나리오로만.
- 내부 설명성 문구(확인 시각, 계산 방식 등)는 넣지 않는다. 이모지 금지(활자 기호 ✦ · 는 허용).
